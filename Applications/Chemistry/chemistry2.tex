	\section{Introduction}
	Writing chemical formulae with chemfig is straightforward.
	
	
	\chemfig{A=B}
	
	
	
	
	To define chemical formulae you can use units that define the angles
	
	\chemfig{A-[1]B-[7]C}
	
	Absolute angles
	
	\chemfig{A-[:50]B-[:-25]C}
	
	Relative angles
	
	\chemfig{A-[::50]B-[::-25]C}
