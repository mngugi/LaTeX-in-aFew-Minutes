This example shows one way to change the numbering of a list; here, changing the value of the counter to start the list numbering at 4 (it is incremented by the command):
\begin{enumerate}
	\setcounter{enumi}{3}
	\item Something.
	\item Something else.
	\item Another element.
	\item The last item in the list.
\end{enumerate}
