	In a document there are different types of \textbf{commands} 
	that define the way the elements are displayed. This 
	commands may insert special elements: $\alpha \beta \Gamma$
	A list example:
	\begin{itemize}
		\item[\S] First item
		\item Second item
	\end{itemize}
